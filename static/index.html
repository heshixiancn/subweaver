客户端使用方法

  1. iOS · Shadowrocket（推荐） — 在 iPhone 上打开本页，点上方「一键导入」。要分组与分流规则，请导入「配置文件」：Shadowrocket → 底部「配置」→ 右上角 + → 粘贴配置链接。
  2. 订阅自动更新 — 设置 → 服务器订阅 → 打开「打开时更新」；配置文件方式则在「配置」页左滑刷新。改动本页配置后，客户端刷新即同步。
  3. macOS · ShadowsocksX-NG — 服务器 → 订阅设置 → 添加订阅链接并勾选自动更新；规则链接（rules.acl）填入「编辑 ACL」。
  4. 备份 / 自建静态站 — output/ 目录已生成 subscription.b64、shadowrocket.conf 与 group-*.b64，可直接部署到任意静态服务器。
订阅链接包含节点信息，请勿公开分享；若泄露请点「重置 Token」立即作废旧链接
